## Introduction

**TechConnect** is a peer tutoring platform for the College of Industrial Technology at Southern Luzon State University. It connects students through live video sessions with interactive whiteboards and real-time collaboration tools.

### Key Features

✅ **Peer-to-peer video sessions** using WebRTC  
✅ **Interactive whiteboard** for visual collaboration  
✅ **Real-time chat** and file sharing  
✅ **Instant & scheduled sessions**  
✅ **Fuzzy search** to find tutors easily  
✅ **Rating system with feedback tags**  
✅ **Voluntary donation** via QR codes  
✅ **Email & in-app notifications**  
✅ **Dark/Light theme** toggle

## Getting Started

### System Requirements

**Minimum:**
- Modern browser: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- Internet: 5 Mbps (10+ Mbps recommended)
- Webcam, microphone, speakers/headphones

**Not Supported:**
- Internet Explorer
- Older browser versions


### Creating an Account

1. Visit `https://cit-techconnect.org`
2. Click **"Sign Up"**
3. Choose role: **Learner** or **Tutor**
4. Fill in:
   - Email address
   - Password (minimum 8 characters)
   - Full name
   - Course
   - Year level
   - Bio (optional)
5. Click **"Create Account"**
6. **Check email** for verification link
7. Click verification link to activate account

**For Tutors:** After email verification, your application goes to administrators for approval (1-3 business days). You'll receive an email when approved or if more information is needed.

### Logging In

1. Go to homepage
2. Click **"Login"**
3. Enter email and password
4. Click **"Sign In"**

### Theme Toggle

Switch between dark and light mode:
- Click theme toggle button (sun/moon icon) in header
- Theme preference is saved automatically

### Booking Sessions

#### Scheduled Session

1. Click on tutor's profile
2. Click **"Book Session"**
3. **Select Date & Time:**
   - View tutor's available slots
   - Choose date from calendar
   - Select time slot
4. **Add Details:**
   - Subject (required)
   - Description of what you need help with
   - Duration estimate
5. Click **"Request Session"**
6. Wait for tutor to accept/decline
7. You'll receive email notification

**Session Status:**
- 🟡 **Pending** - Awaiting tutor response
- 🟢 **Approved** - Confirmed by tutor
- 🔴 **Declined** - Tutor declined (reason shown)
- ✅ **Completed** - Session finished
- ❌ **Cancelled** - Cancelled by either party

#### Instant Session

For immediate help (tutor must be online):

1. Find tutor with 🟢 **Online** badge
2. Click **"Request Instant Session"**
3. **Fill Form:**
   - Subject
   - What you need help with
   - Duration (10-30 minutes)
4. Click **"Send Request"**
5. **Tutor responds in real-time:**
   - If accepted: Session starts immediately
   - If declined: Try another online tutor

**Note:** Instant sessions are limited to 10-30 minutes.

1. After a session, you can donate to your tutor
2. Tutors upload their QR codes (GCash, PayMaya, etc.)

4. Send any amount you choose
5. **Donations are voluntary and not required**

1. Go to tutor's profile
2. Click **"View Donation QR"**
3. Scan with mobile banking app
4. Complete transaction in your app

**Important:**
- Completely voluntary
- No minimum/maximum
- Transactions outside TechConnect
- Platform doesn't process payments

## Troubleshooting

### Cannot Log In

**Problem:** Invalid email or password

**Solutions:**
1. ✅ Verify email spelling
2. ✅ Check Caps Lock
3. ✅ Click "Forgot Password"
4. ✅ Clear browser cache
5. ✅ Try different browser
6. ✅ Check email verification


### Camera Not Working

**Problem:** Black screen or no camera

**Solutions:**
1. ✅ Check camera connected
2. ✅ Allow browser permission
3. ✅ Close other apps using camera
4. ✅ Try different browser
5. ✅ Restart computer
6. ✅ Update browser
7. ✅ Test camera in other apps

**Browser Permissions:**
- Chrome: Settings → Privacy → Camera
- Firefox: Preferences → Privacy → Camera
- Safari: Preferences → Websites → Camera

### Microphone Not Working

**Problem:** Other can't hear you

**Solutions:**
1. ✅ Check microphone connected
2. ✅ Allow browser permission
3. ✅ Check not muted in system
4. ✅ Test in device settings
5. ✅ Try different microphone
6. ✅ Check correct input selected
7. ✅ Restart browser

### Poor Video/Audio Quality

**Problem:** Laggy or choppy

**Solutions:**
1. ✅ Check internet speed (need 5+ Mbps)
2. ✅ Close bandwidth-heavy apps
3. ✅ Move closer to WiFi router
4. ✅ Use wired ethernet
5. ✅ Turn off video, use audio only
6. ✅ Close unnecessary tabs
7. ✅ Restart router

**Speed Test:** Visit speedtest.net

### Cannot Join Session

**Problem:** Session not found

**Solutions:**
1. ✅ Verify session time
2. ✅ Refresh page (F5)
3. ✅ Log out and back in
4. ✅ Check internet
5. ✅ Clear browser cache
6. ✅ Try different browser
7. ✅ Wait for tutor to start

### Whiteboard Not Syncing

**Problem:** Drawings not visible

**Solutions:**
1. ✅ Click **Refresh** button in whiteboard toolbar
2. ✅ Check internet connection
3. ✅ Both toggle whiteboard off/on
4. ✅ Clear browser cache
5. ✅ Try different browser

**Note:** Refresh button reconnects whiteboard without reloading page (v1.1.0 feature)

### Screen Share Not Working

**Problem:** Cannot share screen

**Solutions:**
1. ✅ Allow browser permission
2. ✅ Select correct window/screen
3. ✅ Check share is active
4. ✅ Stop and restart share
5. ✅ Try different window
6. ✅ Update browser

### Connection Issues

**Problem:** Frequent disconnects

**Solutions:**
1. ✅ Check internet stability
2. ✅ Switch to ethernet
3. ✅ Move closer to router
4. ✅ Restart router
5. ✅ Close other devices
6. ✅ Contact ISP

**If Disconnected:**
- Refresh immediately
- Rejoin session
- History preserved

### Browser Compatibility

**✅ Supported:**
- Chrome 90+

**❌ Not Supported:**

## FAQ

### General

**Q: Is TechConnect free?**  
A: Yes, completely free for all CIT students.

**Q: Need to download software?**  
A: No, works in web browser.

**Q: Can I use on mobile?**  
A: Mobile-responsive, but desktop recommended for video sessions.

**Q: How to change password?**  
A: Settings → Security → Change Password

**Q: How to delete account?**  
A: Settings → Account → Delete Account (permanent)

**Q: Is data secure?**  
A: Yes, encrypted and follows university policies.


### For Learners

**Q: How to find good tutor?**  
A: Check ratings, reviews, feedback tags, and subject expertise.

**Q: Can I request specific tutor?**  
A: Yes, book directly with any available tutor.

**Q: What if tutor doesn't show?**  
A: Wait 10 minutes, report issue. Session marked as "Missed by Tutor".

**Q: Can I cancel session?**  
A: Yes, go to My Sessions and click Cancel. Try to cancel 24 hours in advance.

**Q: How long are sessions?**  
A: Scheduled: 30-60 minutes typically. Instant: 10-30 minutes.

**Q: Multiple sessions with same tutor?**  
A: Yes! Add to favorites for easy access.

**Q: Must I donate?**  
A: No, donations are completely voluntary.

### For Tutors

**Q: How to become verified?**  
A: Complete profile, submit for verification. Admins review in 1-3 days.

**Q: If application rejected?**  
A: Review reason, update profile, resubmit.

**Q: Can I tutor multiple subjects?**  
A: Yes, add all subjects you're qualified to teach.

**Q: How to handle difficult learners?**  
A: Stay professional. If disruptive, end session and report to admin.

**Q: Can I set own schedule?**  
A: Yes, complete control over availability.

**Q: Need to cancel session?**  
A: Go to My Sessions, click Cancel, provide reason. Avoid frequent cancellations.

**Q: How do donations work?**  
A: Upload your QR code. Learners scan and send via mobile banking. Transactions outside TechConnect.

**Q: Can I see profile views?**  
A: No, only see learners who book with you.

**Q: How to improve rating?**  
A: Be punctual, prepared, patient, communicative. Use whiteboard effectively.

**Q: Can I tutor other colleges?**  
A: No, TechConnect is exclusive to CIT students.

### Technical

**Q: Internet speed needed?**  
A: Minimum 5 Mbps, recommended 10+ Mbps.

**Q: Best browser?**  
A: Chrome 90+ for best experience.

**Q: Are sessions recorded?**  
A: No, not automatically recorded.

**Q: Can I use offline?**  
A: No, requires internet connection.

**Q: What happens if I delete account?**  
A: Personal info deleted. Session history anonymized for statistics.

**Q: How is privacy protected?**  
A: Encryption, secure authentication, university data protection policies.
