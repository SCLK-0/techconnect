# Deployment Details (Corrected)

The approval request letter will summarize TechConnect's features, requirements, and training plan. The researchers will coordinate with the CIT-SC Adviser and Governor to arrange demonstrations. Prior to handover, the team will complete end-to-end testing in a staging environment that mirrors production. 

During deployment, the researchers and CIT-SC Governor will configure the Vercel hosting environment, deploy the React with Vite front end, and integrate Supabase services, including authentication, database schema, file storage rules, and real-time policies. Domain setup and SSL certificates will also be validated to ensure secure system access.

A comprehensive user manual—covering account management, session booking, resource uploads, dashboard navigation, and troubleshooting—will be finalized and distributed in both printed binders and PDF copies to CIT-SC peer tutors, CIT-SC advisers, and IT experts who evaluated the system. 

Over three days, role-based workshops will be conducted: CIT-SC peer tutors will be trained on profile management, availability scheduling, conducting video sessions with real-time collaboration tools, and resource uploads; learners on registration, tutor browsing and filtering, session booking, and resource access; and CIT-SC administrators (Adviser and Governor) on dashboard review, user management, report generation, and content moderation. Feedback will be collected and questions addressed in real time to ensure all user groups become proficient in using TechConnect.
