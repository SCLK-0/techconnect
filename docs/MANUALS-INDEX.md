## Quick Reference

### For Learners
- **Find Tutors:** Sidebar → Find Tutors → Use search/filters
- **Book Session:** Tutor Profile → Book Session → Select time
- **Instant Session:** Find online tutor → Request Instant Session
- **Join Session:** My Sessions → Join (5 min before start)
- **Give Feedback:** Automatic after session ends

### For Tutors
- **Get Verified:** Complete profile → Wait for admin approval
- **Set Availability:** Availability → Add time slots → Save
- **Go Online:** Toggle online status for instant sessions
- **Accept Requests:** Requests tab → Review → Accept/Decline
- **Upload Resources:** Resources → Upload → Wait for approval

### For Administrators
- **Verify Tutors:** Approvals → Review application → Approve/Reject
- **Monitor Sessions:** Live Monitoring → View active sessions
- **Approve Materials:** Resources → Pending → Review → Approve/Reject
- **Post Announcements:** Announcements → Create → Publish
- **View Analytics:** Analytics → Select metrics → Export reports
