# Figure 3. System Architecture Design of TechConnect

The system architecture of TechConnect demonstrates a comprehensive web-based peer tutoring platform that facilitates interactions among three primary user roles—Administrators, Tutors, and Learners—through a client-server architecture deployed on Vercel with cloud-based infrastructure and real-time communication capabilities. The application employs React 18 as the core user interface library, styled with Tailwind CSS and shadcn/ui components, with Vite serving as the build tool, while Supabase functions as the comprehensive backend-as-a-service layer providing authentication management, PostgreSQL database operations, object storage, real-time data synchronization via WebSocket protocol, and serverless Edge Functions for email notifications through the Resend API. The React-based interface implements a component-driven architecture enabling users to perform essential operations including profile management, tutor discovery through fuzzy search algorithms with filtering by subject area, rating thresholds, academic year level, and real-time availability status, session scheduling for both scheduled and instant sessions, resource access, feedback submission with star ratings and categorical tags, and real-time video communication through PeerJS, a WebRTC abstraction library that establishes peer-to-peer connections without intermediary servers, integrated with a collaborative whiteboard utilizing Fabric.js for canvas manipulation, real-time text-based chat, screen sharing functionality, and file transfer capabilities. Supabase Auth implements secure user authentication with email verification workflows and password recovery mechanisms, the PostgreSQL database maintains persistent storage for user accounts, tutor profiles with availability schedules, session records, feedback data, learning materials, system notifications, collaborative whiteboard states, and chat message histories, Supabase Storage manages binary large objects including user avatars, educational resources, and donation QR code images with row-level security policies, and Supabase Realtime provides bidirectional communication channels enabling instantaneous updates for session status changes, notification delivery, whiteboard state synchronization, and chat message delivery. Administrators access specialized dashboard interfaces to perform platform governance tasks including tutor credential verification, user role management, learning material moderation, real-time session monitoring, and system analytics review, while Tutors configure weekly availability schedules with date-specific overrides, toggle online status for instant session availability, maintain profile information including subject expertise, upload educational materials subject to administrative approval, configure donation QR codes for voluntary monetary contributions, respond to session requests, and conduct video sessions with integrated collaborative tools, and Learners maintain favorite tutor lists, initiate session requests, participate in video sessions through a waiting room mechanism, submit structured feedback, review session history, and make voluntary donations via displayed QR codes. A typical interaction sequence initiates when a user engages with the React interface, which authenticates users through Supabase Auth, executes data operations on the PostgreSQL database utilizing TanStack Query for optimized state management and request caching, and establishes subscriptions to Supabase Realtime for live data updates; when a learner initiates a session request, the system creates a corresponding database record, triggers real-time notifications to the designated tutor via Supabase Realtime channels, and dispatches email notifications through Edge Functions interfacing with the Resend API, upon tutor acceptance both parties receive instantaneous notifications, and at the designated session time participants join the video interface where PeerJS negotiates and establishes a peer-to-peer WebRTC connection for bidirectional audio and video streaming, with the collaborative whiteboard and chat messaging system maintaining real-time synchronization through Supabase Realtime and state changes persisted to the database for session continuity and historical record, and upon session conclusion the learner receives a prompt to submit structured feedback including numerical ratings and categorical tags, with optional donation QR code display if configured by the tutor. This architecture provides secure authentication with email verification protocols, reliable data management through PostgreSQL with row-level security policies, scalable object storage, efficient real-time communication via WebSocket connections, peer-to-peer video sessions eliminating external service dependencies, collaborative tools with synchronized whiteboard and chat functionality, and comprehensive in-app notification delivery, collectively delivering a streamlined, responsive, and secure peer tutoring experience suitable for academic environments.
