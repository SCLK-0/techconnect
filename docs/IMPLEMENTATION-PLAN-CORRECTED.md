# Implementation Plan

The deployment of the TechConnect system for the CIT-SC (College of Information Technology - Student Council) was conducted in an organized and systematic method to ensure its success. The implementation plan outlines the major activities, persons involved, and timeline for the deployment process. The implementation was carried out in phases:

| Strategy | Activities | Persons Involved | Duration |
|----------|-----------|------------------|----------|
| Securing Institutional Approval | Prepared and submitted a formal request letter to the CIT Dean and University IT Services detailing project objectives, system capabilities, and required resources. Followed up on any inquiries or requested clarifications from the approvers. | Researchers, CIT Department Head, University IT Staff | 3 Days |
| System Deployment | Configured the hosting environment on Hostinger (Node.js plan). Deployed the Next.js-based React application build together with Node.js serverless functions. Set up Supabase services (Authentication, Database Schema, Storage, and Real-Time Rules). Verified domain configuration and SSL certificate issuance. | Researchers, CIT IT Personnel | 1 Day |
| Distribution of User Manuals | Finalized and printed the user manual, covering account management, session booking, resource uploads, dashboards, and troubleshooting guidance. Distributed printed and digital copies of the user manual to CIT IT Personnel, peer tutors, and faculty advisors. | Researchers, CIT IT Personnel, Peer Tutors, Faculty Advisor | 1 Day |
| Training Sessions | Conducted hands-on workshops for: CIT IT Personnel (system configuration, user account administration, analytics reporting). Peer Tutors (creating/maintaining profile, managing availability, conducting sessions, uploading resources). Learners (account registration, searching for tutors, booking sessions, accessing resources). Administrators (reviewing dashboards, generating reports, moderating content). Collected feedback and answered questions in real time to ensure comfort with all system functions. | Researchers, CIT IT Personnel, Peer Tutors, Learners, Administrators | 3 Days |

Table 1. Implementation Plan of TechConnect System

The implementation plan started with obtaining official approval from the CIT Dean and University IT Services, ensuring that the appropriate permissions were in place before proceeding. This was followed by the system deployment phase, wherein the hosting environment was configured on Hostinger, the Next.js-based React application was deployed along with Node.js serverless functions, and Supabase services were integrated, including authentication, database schema, storage, and real-time rules. Domain configuration and SSL certificates were verified to ensure secure system access.

Once deployment was complete, the team finalized and distributed comprehensive user manuals in both printed binders and PDF copies to CIT IT personnel, peer tutors, and faculty advisers. The manuals covered account management, session booking, resource uploads, dashboard navigation, and troubleshooting guidance to equip users with the knowledge required to utilize the system effectively.

Training sessions were then conducted over three days in a production-mirrored lab environment. CIT IT staff were trained on system configuration, user account administration, and analytics reporting to enable them to manage and maintain the platform. Peer tutors received training on creating and maintaining their profiles, managing availability schedules, conducting tutoring sessions, and uploading learning resources. Learners were guided through account registration, searching for tutors, booking sessions, and accessing educational materials. Administrators were trained on reviewing dashboards, generating reports, and moderating content to ensure platform quality and compliance. Feedback was collected and questions addressed in real time to ensure all user groups became proficient in using TechConnect.

The final phase involved formal handover to CIT IT personnel, who have taken over maintenance and updates of the system. A formal handover agreement marked this transition, transferring the full system, source code, hosting configuration, and user manual to CIT IT personnel, after which researchers no longer provide routine support.
